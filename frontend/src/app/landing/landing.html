Three steps, no surprises

  1. 1

    Create the link

    Paste any http(s) URL. You get a short permanent identifier — that's what gets encoded into the QR.

  2. 2

    Print or share the QR

    Download the QR as PNG or SVG. Put it on a menu, poster, sticker, business card — whatever the physical world needs.

  3. 3

    Change the destination, anytime

    Edit where the link points whenever you want. Every previously printed QR keeps working and now leads to the new target.

What makes this different

🛠️ Open-source, MIT

The full code is on GitHub. Fork it, audit it, run it, sell what you build on top of it. No “community edition” with the good parts missing.

🕶️ IP never stored

Scan logging is async. The visitor's IP is resolved to a country code in flight, then dropped. The scans table literally has no IP column.

♾️ Codes that never expire

As long as your instance is running, the QR you printed three years ago still works — and still points wherever you tell it to today. No hostage model.

Self-host in one command

Docker + Docker Compose. That's the entire dependency list.

git clone https://github.com/<you>/qr-code-redirect.git
cd qr-code-redirect
cp .env.example .env       # tweak APP_SECRET, JWT_PASSPHRASE, etc.
docker compose up -d --build

Brings up Postgres, Redis, the API, the dashboard, the async worker, and the periodic janitor — with healthchecks, restart policies, and JWT/migrations handled automatically on first boot.
